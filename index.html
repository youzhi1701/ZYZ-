01 / ABOUT · 个人简介

我更在意问题怎么被解决，
而不是用了多复杂的技术。

电商让我习惯从商品和结果出发，AI 让我重新理解一个人能完成多少工作， 自动化则让我开始认真审视那些每天重复出现的动作。 对我来说，AI 不是聊天工具，自动化也不是炫技。 它们真正有价值的地方，是能不能进入工作流程，少一点重复，少一点等待，少一点没必要的操作。

03 / PROJECTS · 项目经历

项目不一定大，

这里不放虚构的大厂经历，只放我自己经营、搭建、研究和持续优化过的东西。

PROJECT 01 / PRECIOUS METAL E-COMMERCE

贵金属电商经营

真实经营

从产品本身，一直做到消费者真正看到它。

围绕实物白银做产品规划、不同克重组合、京东与淘宝视觉、商品标题、价格体系、 消费者反馈、包装、售后规则和供应链沟通。 这类项目让我真正理解：视觉、价格、规则和信任感必须同时成立。

PROJECT 02 / MARKET SYSTEM

贵金属实时行情系统

白银为核心的实时数据看板

整合销售价、回购价、黄金、铂金、K 线、分时、预警、AI 行情摘要、涨跌和数据延迟，目标是高密度但不难读。

PROJECT 03 / AUTO PRICING

电商自动化改价系统

行情数据 + 店铺策略 + 自动执行

获取白银行情数据，结合不同店铺基础价和溢价策略自动计算销售价格，并输出运行状态通知。

PROJECT 04 / DAILY REPORT

自动成交数据日报

把多个店铺数据压缩成一屏重点

自动汇总成交额，计算预估克重、预估克价、各店铺成交情况和当前行情，再生成简洁日报。

PROJECT 05 / DIGITAL ASSET

本地照片与视频资产整理

处理 TB 级历史媒体文件

使用 ExifTool、PowerShell、CSV 和文件元数据研究拍摄日期、创建时间、批量扫描、目录整理和检索方案。

PROJECT 06 / AI VISUAL

AI 辅助视觉生产

先保真，再增强展示

建立银条、电商主图的产品还原规则，保证形状、比例、厚度、纹理、钢印与银色质感不变，再调整 UI、背景、灯光和信息层级。

PROJECT 07 / PERSONAL WEB

个人网站 / 数字名片

不是一次性简历，而是长期更新的主页

用来放个人介绍、能力体系、项目、时间线、正在研究的事情，以及以后更多可以被访问和持续更新的内容。

04 / HOW I WORK · 我的工作方式

我更愿意先做出一个能跑的版本，
再让真实使用告诉我哪里不对。

01

发现问题

很多项目都从一个很具体的麻烦开始。先把真正浪费时间的点找出来。

02

快速找办法

不会局限在某一种工具。能用 AI、RPA、表格、脚本或现成项目解决，就先用合适的。

03

先做出来

相比长时间讨论，我更倾向于先做出一个可运行版本，让问题尽快暴露。

04

持续修改

真正开始使用以后出现的问题，通常比最开始的设想更值得解决。

05

最后形成自己的系统

如果一个流程长期有效，我会把零散工具、规则和经验逐步整理成可重复使用的方法。

07 / TIMELINE · 个人时间线
