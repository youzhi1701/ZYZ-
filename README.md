# ZYZ-com · 蔡宏亮个人主页

> 轻量、纯前端的个人数字主页，用于集中展示个人介绍、能力结构、项目实践和工作方式。

| 项目 | 信息 |
| --- | --- |
| 当前版本 | **v2026.10.07** |
| 项目类型 | 个人主页 / 作品集 |
| 技术形态 | HTML + CSS |
| 当前状态 | 持续迭代 |

---

## 项目概览

ZYZ-com 的目标不是做传统招聘模板，而是做一个具有个人品牌感、打开速度快、信息层级清晰的数字主页。

视觉方向以 **浅色极光 + iOS 毛玻璃 + 大字号排版** 为主，同时控制高性能开销，避免为了视觉效果加入无意义的重型 3D、粒子或复杂依赖。

---

## 核心内容

当前主页主要包含：

- 个人品牌与首页 Hero
- 关于我
- 能力结构
- 重点项目
- 工作方式
- 时间线
- 当前推进事项
- 项目 Archive

内容围绕电商、AI、自动化、数据工具和产品实践展开。

---

## 设计原则

- 浅色极光背景
- iOS 风格毛玻璃卡片
- 柔和渐变与光斑
- 大字号标题与明确视觉层级
- 轻量滚动动画与微交互
- 响应式布局
- 内容优先、性能优先
- 避免重复板块和无效留白

## 快速开始

无需安装依赖或构建工具，直接打开：

```text
index.html
```

也可以使用任意静态服务器：

```bash
python -m http.server 8000
```

然后访问本地 8000 端口。
