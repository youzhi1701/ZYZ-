# ZYZ-com · 蔡宏亮个人主页

一个轻量、纯前端的个人主页 / 作品集项目，用于集中展示个人介绍、能力结构、正在推进的项目和工作方式。

页面采用浅色极光、毛玻璃和大字号排版，目标是做成有个人品牌感的数字主页，而不是传统招聘模板。

---

## 页面内容

当前主页主要包含：

- 个人品牌与首页 Hero
- 关于我
- 能力结构
- 重点项目
- 工作方式
- 时间线
- 当前正在推进的事项
- 项目 Archive

内容围绕电商、AI、自动化、数据工具和产品实践展开。

---

## 设计方向

当前视觉重点：

- 浅色极光背景
- iOS 风格毛玻璃卡片
- 柔和渐变与光斑
- 大字号标题与清晰信息层级
- 轻量滚动动画
- 响应式布局
- 避免过量 3D / 粒子等高性能开销效果

项目保持纯前端实现，优先保证打开速度和浏览流畅性。

---

## 技术结构

无需构建工具和后端服务。

```text
ZYZ-com/
├─ index.html    # 页面结构与内容
├─ style.css     # 全部视觉样式与响应式布局
├─ 1             # 项目保留文件
└─ README.md
```

---

## 本地预览

直接双击 `index.html` 即可打开。

也可以使用任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后在浏览器访问本地 8000 端口。

---

## 部署

这是标准静态站点，可以部署到：

- GitHub Pages
- Vercel
- Cloudflare Pages
- Netlify
- 任意支持静态 HTML/CSS 的服务器或对象存储

部署时只需要确保 `index.html` 与 `style.css` 保持在相同目录关系下。

---

## 修改内容

个人介绍、项目文案、时间线等主要内容直接位于：

```text
index.html
```

整体视觉、毛玻璃、极光、响应式和动画规则位于：

```text
style.css
```

如果后续继续扩展，建议保持当前“内容优先、性能优先”的原则，避免加入对个人主页价值不大的复杂依赖。
